## 1. 계약 만기 소스 3종 — #562

기존 5종(면허·법정교육/검진·4대보험 신고·방사선 장비검사·재고 유효기간)에 **계약 만기** 추가:
- **위수탁·구매 계약**(scm.OutsourcingContract): 유효(ACTIVE/EXPIRING) 계약의 `end_on` 임박. 자동갱신
  계약은 status "자동갱신" 구분 표기(취소 가능성 대비 노출 유지). 만료·해지·초안 제외.
- **의료진 계약**(hr.MedicalStaffContract): 유효 계약·`valid_to` 설정분.
- **근로계약(계약직)**(hr.Employee.contract_end): 재직 중(resigned_on NULL) 계약직만(정규직·퇴사 제외).

## 2. 의료폐기물 보관기한·의약품 회수 — #563

- **의료폐기물 보관기한**(scm.MedicalWasteLog·기한형): 미인계(STORED) 폐기물의 **법정 보관기간 도래분**.
  `due = stored_on + 종류별 한도`(폐기물관리법 시행규칙 별표5 냉장 기준 — 손상성 30일·그 외 15일, 상온은
  더 짧으므로 보수적 조기 경고). 보관기간 초과 시 위반.
- **의약품 회수 미조치**(scm.DrugRecall·경보형): OPEN 회수(식약처 회수명령·영향 로트 격리/폐기 미완료)
  건수를 `alerts.drug_recall_open`으로. 웹 경보 배지(red).
- 차입금 상환은 재무 도메인이라 컴플라이언스 초점 유지 위해 제외.
