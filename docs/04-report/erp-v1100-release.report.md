## 1. 계약·조달·결재 라이프사이클 (이번 릴리스 핵심)

### 1.1 위수탁계약(CLM) 생애주기 세분화 — #503·#504 (마이그 0138)
3단계(ACTIVE/EXPIRED/TERMINATED) → **8단계 상태머신**(DRAFT→PENDING_APPROVAL→APPROVED→ACTIVE→
EXPIRING→EXPIRED→TERMINATED/REJECTED). 승인 직무분리·발효일·금액변경 이력·만기 자동전이 배치·
월 위탁료 month-end 자동 발생(멱등)·e-sign 완료→발효 트리거.

### 1.2 의료계약 통합 — #505·#506·#507 (마이그 0139·0140)
위수탁·의료진계약을 **공통 생애주기 커널**(`common/contract_lifecycle`)로 일원화. 변경이력
`common.contract_amendments`로 승격(다형 kind). 의료계약도 8단계·승인·발효·해지사유 획득(ENDED→TERMINATED
무손실 이관). e-sign 발효 트리거 양 계약 통일.

### 1.3 N단계 결재선 엔진 + 최고경영자 전권 — #508·#509·#510 (마이그 0141)
PO·위수탁·의료계약 단일 승인을 **다단계 결재선**으로 일반화한 공통 엔진(룰 매칭·금액대·ROLE/부서장/지정자
단계). 룰 없으면 레거시 단일승인 폴백(무중단). **전권 결재(executive override)**: 원장(DIRECTOR)이 결재선
건너뛰어 즉시 확정(잔여 단계 SKIPPED·직무분리 유지·감사 OVERRIDE).

### 1.4 RFQ/견적/단가계약 소싱 + 일반 구매계약 + 계약 PDF — #511·#512·#513 (마이그 0142·0143)
구매 상류 소싱(RFQ→견적→비교→낙찰→단가계약→PO 계약단가 자동적용). 위수탁 전용 CLM을 일반
구매/용역/임대·월정액/일회성(contract_type·billing_type)으로 확장. 계약서(안) PDF 자동생성(변경이력 포함).
