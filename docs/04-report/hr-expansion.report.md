## 1. 배경 — 인사 기능 검토 (Plan)

HIS에서 직원 등록작업 준비 중 → "ERP 인사관리 가능 기능 검토, 빠진 것은?" 질의.
17개 모듈·39개 엔드포인트 전수 검토 결과: 기반(직원·발령·면허·연차·당직·급여·퇴직급여·인센티브)은
완비, **공백 11건** 식별 → 우선순위 P0(3)·P1(3)·P2(5) 분류.

핵심 발견:
- 급여 generate가 기본급·부양가족을 **매월 body로 수동 입력** (비영속) — 최대 병목
- **퇴사 처리 경로 자체가 부재** (resigned_on 설정 코드 없음)
- staff_sync는 Clinic 전용 — HIS 직원 등록 스키마 합의 필요
