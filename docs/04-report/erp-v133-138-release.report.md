## 3. 하이라이트

### 3.1 실사용 손익에 직결된 수정
- **환불 계정 비대칭(H-4)**: 카드 환불이 무조건 현금(1110) 대변 → 카드미수(1132) 미소멸·현금시재 왜곡.
  수납(`_revenue_lines`)과 대칭으로 정정.
- **날짜 UTC off-by-one(FE-2)**: KST 00~09시에 일마감·재고실사·수납 일자가 "어제"로 기록되던 광범위 결함.
- **휴일근로수당(H-2)**: 표시 카탈로그엔 있었으나 계산이 부재 — 법정수당 누락 해소.
- **소득세 fail-safe(H-1)**: 세법 개정 시 무음으로 구식 세액을 내던 비대칭을 4대보험 RATES와 동형으로.

### 3.2 검토 → 거버넌스 승격(사용자 제안)
단발 수정이 아니라 재발 구조를 차단: 수당 단가는 **발효일 기간 이력**(연 단위 단협 갱신·불변 로그·급여월
기준 적용), 법정 상수는 **레지스트리 가시화+연말 만기 경보**(미등재로 해 넘기면 fail-safe 정지의 사전 짝),
야간수당은 **정책 설정**(FLAT/법정/MAX), 회계 기간은 **기관 회계연도 설정**.

### 3.3 검증·배포
