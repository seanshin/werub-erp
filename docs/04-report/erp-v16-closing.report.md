## 1. 진료비 명세 심사 작업대 (#166·#167·#173·#174)

사용자 요청: "상세 버튼 → 계산수식·본인부담 구성·세부 분류 + AI 공시질의".

| 축 | 내용 |
|----|------|
| 급여 6분류 + 비급여 4분류 | 진찰료·입원료·식대·행위료·약제비·치료재료대 / 상급병실료·선택진료비·특수검사·제증명 — `billing_classify`·fee_master.benefit_category(명칭 백필) |
| 본인부담 정밀화 | 기관 종별(병원40%·시점관리 `InstitutionGradeSetting`)·산정특례 유형별·의료급여 1·2종·**보훈(국비 면제)**·시간가산(야간/공휴 판정) |
| 단가 근거 추적 | 라인에 fee_master 시행일(valid_from)·유효기간·출처 노출 |
| AI 공시 질의 | 라인별 `ai-diagnose`(삭감위험+공시 인용)·자유 `ai-search` 패널 |

라인별 계산식(`85,000 × 3 = 255,000 → ×40% 본인부담`)·codeType 그룹 소계·적발 인라인 연결.

## 2. 의료진 협업 루프 (#172) — "삭감되지 않은 결과물"

```
심사팀 위험 식별 → 의료진 질의(적발/라인 둘 다) → 회신(근거 EVIDENCE | 수정 REVISE)
  ├ 근거 인정(ACCEPTED) → 연결 적발 자동 DISMISS → 케이스 위험 제거
  └ 수정 완료(REVISED) → 오더 수정 통보
```
`PreReviewQuery`/`Reply`(마이그 0051). 운영 E2E: 적발 3→2(근거 인정으로 위험 제거). 채널 P2=ERP 내부, P3 릴레이(W.Sign 대기).

## 3. 약품 코드 자동 매핑 — 일회성에서 영구 구조로 (#178~#181·트랙 종결)

사용자 통찰: "신규 코드도 자동 매핑하는 기능이 필요하지 않나?"

```
미등재 31종(비표준코드 M*) 진단 → 표준화 요청 → 자동 매핑 레이어
  → 매칭엔진(brand+dose·제형군·신뢰도) → 약제팀 확정(양측 화면)
  → ERP confirmed EP ↔ HIS pull/백필 → 표준 청구 → MASTER
```
- `DrugCodeMap`(0053): SUGGESTED→CONFIRMED→invoice `price_source=MAP`(보험코드 약가)
- 제형 정밀화(정↔주사·현탁액 오매칭 해소)·약가 현행 폴백(temporal)
- **양측 21건 일관 수렴**(ERP 확정 20 + 동기화 1, HIS 25/51). 혈액제제=혈액수가/특수주사제=함량보강
- 신규 약품도 자동 대응(일회성 스크립트 → 상시 레이어)
