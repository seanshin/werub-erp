## 1. 컴플라이언스 만기·한도 통합 대시보드 (이번 릴리스 핵심) — #558

여러 도메인에 흩어진 법정 기한/한도를 **하나의 운영 뷰**로 집계(신규 도메인 데이터 없이 기존 데이터 재사용).

- **기한형(긴급도 밴드 경과/D-7/D-30/D-90)**: 면허 만료(hr.License·무기한 제외)·법정교육/건강검진 이수
  만료(hr.ComplianceRecord)·4대보험 신고 기한(hr.InsuranceReportEvent PENDING)·방사선 장비 정기검사
  (regulatory.RadiationEquipment)·재고 로트 유효기간(scm.Lot 잔량>0). 카테고리별 요약.
- **비기한형 경보**: 방사선 피폭 연한도(50mSv) 근접(80%)/초과·환자안전 미검토(REPORTED/REVIEWING).
- **아키텍처**: `erp.app` 크로스도메인 오케스트레이션 레이어(analytics는 규제 직접 접근 import-linter
  계약상 금지). `GET /compliance/deadlines?as_of=&horizon_days=` + 신규 스코프 `regulatory.compliance`
  read(직원명 포함이라 경영·관리 역할 전용). 웹 `/compliance`(긴급도 KPI·경보 배지·만기 테이블)·규제 메뉴.
- 읽기 전용(변경 없음 — 각 도메인 서비스가 등록/처리 담당). prod 실데이터 집계 검증.

## 2. 인박스 웹훅 서명 nonce (재생 방지 심화) — #557

전체검토 보안 갈래가 지적한 "재생창 내 논스 부재" 해소. 발신측 eapproval `_assert_callback_nonce`와 동형.
- 서명 통과 후 **Redis NX 단일소비** — 신선도 창(max_skew) 내 동일 서명 재전송 차단(특히 갱신성 이벤트
  `_UPDATABLE_EVENTS`의 창내 재생으로 상태를 되돌리던 여지 제거).
- Redis 장애 시 생략(가용성 우선·ts 신선도가 하드 상한). ENFORCE=하드 거부, OFF=관측 로그.
- **OFF 기본** — HIS 발신 서명 배포 후 활성화 준비 완료.
