## 1. 배경

병원 IT 하드웨어·소프트웨어가 대장으로 관리되지 않아 (누가 무엇을 보유·보증/라이선스 만기·비용·PHI
통제) 흩어져 있었다. 기존 `finance.FixedAsset`은 **감가상각·재무제표**용이라 배정·생애주기·라이선스 준수
같은 **운영 정보**를 담기에 부적합. ITAM을 **운영 대장**으로 신설하고 회계 자산과는 FK로 연결(중복 없음).

기획은 2갈래 검토(재사용 주장 코드 검증 + 병원 특수성 도메인 갭)로 보완(v0.2)했다 — 과대 재사용 주장
(마감 체크리스트·이상탐지=신규) 정정, 병원 특수성(PHI·의료기기·환율·분실도난) 반영, 등록 워크플로
(QR·사진·계약) 추가.

## 3. 핵심 기능 (도메인)

### 3.1 하드웨어 대장 (M1)
- `itam.it_assets`: asset_tag(QR/바코드)·시리얼(unique)·상태 8종(재고/배정/수리/대여/분실/도난/불용/폐기)·
  **소유 부서 vs 사용자 분리**·**네트워크 1급 필드**(IP/host/MAC)·**PHI/보안**(handles_phi·암호화·백신)·
  의료기기(UDI/품목허가/교정)·도입일·보증·장비 디테일(spec)·정비/회수/정기점검 예정.
- 배정/반납(open 이력·**수령확인 chain-of-custody**)·QR 스캔 조회·목록 필터(분류/상태/PHI/배정)·카운트.
- **사용자 = 직원 선택**(드롭다운·등록 시 배정·이름 표기), 일괄편집(스프레드시트·태그 키·식별자 열 락).

### 3.2 소프트웨어·디지털 서비스 (M2a)
- `itam.software_services`: 구매SW·SaaS·AI·클라우드를 **유형 필드로 유형화**(과금 영구/좌석/사용량)·
  좌석·라이선스 메트릭·통화(USD)·자동갱신·**해지 통보일**·**등록/개시/유료 첫 결제일·결제방식(선불/후불/
  무료기간)**·라이선스 키 AES-GCM 암호화(마스킹)·계약/무형자산 연결.
- 좌석 배정(`service_allocations`)·**라이선스 준수**(open vs seats·초과=위반·미사용=절감).

### 3.3 비용 원장·주기 점검 (M2b)
- `itam.service_costs`: 월 비용(정기료+사용량)·**외화 KRW 환산**(fx_rate·amount_krw)·출처.
- `itam.cost_reviews` + run_review: **전월 대비 ±30% 변동 감지**(급증/급감)·**미입력 플래그**·책임자
  확인(확정 보존). **배치 job_cost_review(매월 3일)** 자동 점검·관리자 알림. OPEX 집계(유형별).

### 3.4 유지보수·폐기 (M3)
- `itam.maintenance_records`: 수리/점검/업그레이드/교정 이력.
- **폐기 데이터 소거 게이트**: **PHI 취급 장비는 data_erased 확인 후에만 폐기**(정보보호 안전성 확보조치 감사).

### 3.5 운영 연계 (M4)
- **퇴사 회수(offboarding)**: 퇴사자 미회수 IT 자산·SW 좌석 집계·반납/좌석해제 원클릭.
- **QR 실사**: 태그 스캔→위치 갱신(카메라 스캔 재사용). **의료기기 교정** 만기 대시보드 연계.

### 3.6 컴플라이언스 대시보드 통합
`app.compliance`에 ITAM 소스 **6종** 추가: 구독 만기·**자동갱신 해지 데드라인**·IT 자산 보증·IT 벤더 계약·
**의료기기 교정**·IT 정기점검·**IT 자산 회수**(⑩~⑮).
