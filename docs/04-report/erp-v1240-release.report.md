## 1. 환불 마감 게이트 + 표기 잔여 — v1.23.1 (#649)

환자 도메인 심층 재검토(#630)의 마지막 잔여 **"환불 일마감 집계 밖 전기(마감보고≠GL)"** 종결.

- **마감 게이트**: `pay()`는 마감일 차단(FR-54)인데 `refund()`는 마감된 날짜로 소급 전기 가능하던
  비대칭 → `_lock_closing_day`+CLOSED 검사(pay 대칭). 실제 반환일(미마감)로 전기 유도.
- **일계표·이력 환불 병기**: preview/history에 `refund_total`·`net_cash`(수납−환불) — 마감 전표에
  환불이 없는 구조(자기 전표 refund-N)를 표기로 보완, 현금 시재 대사 오해 차단. 마이그 불요.
- **세무서식 기관정보**: 신고서식 xlsx에 상호·사업자번호·대표자 헤더행(기관 설정 연계·미설정 생략).

## 2. 의약품 표준코드 마스터 — v1.24.0 (#651~653 · 마이그 0163)

사용자 제공 심평원 **약가마스터_의약품표준코드**(2025-10-31판·CP949·52MB)를 참조 마스터로 도입.
표준코드(GS1 880…)↔품목기준코드↔제품코드(보험 EDI)↔성분코드 브리지.

- **적재**: `regulatory.drug_std_codes` + 로더(전량 교체·dedupe·판본 추적). 실파일 검증 후
  **prod 305,522건 적재 완료**(제품코드 보유 65,283·취소 74,680). 로더 `session_factory()()` 핫픽스(#653).
- **매칭 폴백**: fee_master 표기와 다른 상품명을 마스터로 브리지 → 제품코드 → fee_master 현행 검증.
  취소·약가 미등재 제외. **단일 후보라도 MEDIUM 상한**(자동확정 방지 — 약제팀 거버넌스 유지).
- **워크스테이션**: `GET /inventory/items/drug-std` — ERP 미등록 의약품 바코드 스캔 식별.
- **AI 서버 검토 결론**: weve 계약(notice search/diagnose)에 의약품 전용 EP 없음(서버측 유무는 HIS
  확인 항목). 30만행 구조화 마스터의 RAG 색인 **비권고**(로컬 조회가 정확). 반영분 = ai-review 진단
  컨텍스트에 성분코드·ATC·전문일반 투입(#313 최소필요정보 정합).
