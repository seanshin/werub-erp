- **D-6 3차 대사**: 백필 106라인(40차트·101코드·전 보험유형) 100% 적재. invoice 실금액 — 외래 NHIS 85,000→본인 34,000(40%), 비급여 180,000 전액, 자보/산재 본인 0, 혼합 단가소스(MASTER 70·HIS 폴백 36)
