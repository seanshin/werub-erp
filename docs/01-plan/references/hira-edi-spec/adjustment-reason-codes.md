## 조정사유 코드 분류 (알파벳 첫 글자)

| B | 요양급여기준 적용착오 비용 조정 | 상병명 오류, 동일부위 중복 행위 중 주된 것만 인정 |
| C | 요양급여기준 범위 초과 비용 조정·처방내역 미확인 | 기준 범위 초과, 미확인 조제 |

| G | 중복청구비용 조정 | — |

## 통보서 용어 → MEDRLT 필드 매핑 힌트

| 용어 | 정의 | 파서 매핑 |
|------|------|----------|
| 심사차수 | 통보 주기별 번호 (연.월.번호) | UNH message_ref |
| 접수번호 | 접수 식별 | SG1 RFF → batch.receipt_no |
| 명일련(명번호) | 명세서 일련번호 | SG3 RFF → stmt_serial |
| 청구액 | 명세서 청구액 | MOA → claimed_amt |
| 소계1 / 소계2 | 진찰·약제·재료 조정액 / 행위료 조정액(종별가산 포함) | MOA 분리 한정자 (실물 대조) |
| 심결총진료비 / 심결본인부담 / 심결조합부담 | 심사 결정액 3분해 | MOA → decided_amt 계열 |
| 실지급액 / 환불금 / 추가부담 | 지급 정산 | SG6 계열 |
| 코드·명칭·조정사유·조정금액 | 조정 라인 (행위료는 **종별가산 전 금액**) | LIN/ALC/FTX/MOA(129) |

## 수신 절차 (실물 확보 — 의료보험팀 안내용)

- 포털: 진료비청구 → 심사결과통보서조회 → 진료년월 → 접수번호 → 심사조정건조회 → 명일련 → 조정코드·사유
- 청구 SW: [EDI] → EDI 문서수신 (KT-EDI/청구포털 무관 동일 메뉴) → **수신 원본 파일이 PC에 저장됨**
