## 가감률 — 마목 ⑶ 원문

- 상급종합: S = 1등급 입원료의 **+15%**, 1등급 = 기준, 2등급 = 1등급의 −10%, 3등급 = 2등급의 −10% (연쇄)
- 종합병원: S = A의 +12%, A = 1등급의 +12%, 1등급 기준, 이하 직전 등급의 −10% 연쇄
- 수가코드 체계: `AB1AS/151AS …` (종별·등급별 — 원문 파일 참조)
- 폐쇄병동 별도 신고 시: 상급종합 3등급 / 종합 5등급 / 병원 6등급 입원료 적용

## 산정 규칙 (고시 제2023-235호 + 복지부 QA — 엔진 반영 완료)

1. 기간: **전전분기 마지막 월 15일 ~ 전분기 마지막 월 14일**
2. 일별 환자수(24시 기준) = 0시 재원 + 당일 입원 − 당일 퇴원 / 6시간 미만 제외·전과는 24시 점유 병동·외박 포함·간호간병통합/호스피스 제외
3. 간호사: 재직일수 합 ÷ 기간 일수. 제외 — 간호감독·전임노조·가정간호·호스피스·순환근무·연속 부재 16일+. 단시간 16~40h → **0.4/0.5/0.6/0.7/0.8/0.9인** (4h 구간별, 16h 미만 제외)
4. 소수점: 평균 = **셋째자리에서 반올림**, 비율 = **셋째자리 이하 절사** (고시 라.4 원문 — "5자리 반올림" 아님)
5. 미신고: 의원급 6등급, 그 외 산정지침 마목(4)
