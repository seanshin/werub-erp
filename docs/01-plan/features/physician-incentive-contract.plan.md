# 의료진 개별계약 + 성과급(인센티브) 계산·등록·관리 기획서 (P4)

> **요약**: 의료진(특히 의사)은 호봉이 아닌 **개별 계약 + 성과급(인센티브)** 구조다. (A) **의료진 계약을
> 별도 관리**(계약별 기본급·성과급 산식·진료수당·당직·기간)하고, (B) **의사별 진료실적**(수납−직접원가−
> 삭감)을 집계해 계약 산식대로 **성과급을 계산·등록·승인·급여 반영**한다.
> **작성일**: 2026-06-09 · **버전 v1.1**(검토 보완) · **상태**: 기획(협의) · **우선순위**: Med-High(노무
> 민감) · **연관**: P1~P3 급여, costing(ABC), claims(청구·삭감), patient(Reception.doctor_id·Payment)

> **v1.1 검토 보완 요약**: ① **실적 기준을 '수납액'→'총진료수익(발생주의)'로 정정**(§5.5) — 수납은
> 본인부담만이라 과소, 청구 기반(공단+본인부담)이어야. ② **귀속 규칙**(협진·검사 판독·공동진료)
> 추가(§6.5). ③ **회계·세무 통합**(성과급=인건비 전표·미지급·원천징수 재계산)(§7.5). ④ **소급
> 정정**(삭감 확정 시 claw-back)(§7.6). ⑤ **예산·상한 통제**(§11.5). ⑥ **과잉진료 유인 규제·윤리
> 리스크**(§13). ⑦ doctor_id↔Employee 매핑·비급여 실적·시뮬레이션 결정 추가.

## 1. 배경 / 요구

- **의료진 계약은 별도**: 일반직(호봉)·일용(일당)과 달리 의사는 **개별 협상 계약** — 기본 연봉 + **성과급
  조건이 계약마다 상이**(순수입 배분율·진료과 배분·목표). 표준 급여체계로 못 담음.
- **성과급 계산·등록·관리**: 의사별 진료실적을 집계 → 계약 산식 적용 → 성과급 산정 → 승인 → 급여 반영.
  노무·금액 민감 → 투명·근거·승인·감사 필수.

## 2. 현황 / 자산 (재사용)

| 자산 | 위치 | 활용 |
|------|------|------|
| **담당의 귀속** | `patient.Reception.doctor_id`(·Reservation·Claim) | 의사별 진료실적 집계 키 |
| 수납액 | `patient.Payment.amount` | 진료수익(순수입 산정) |
| 직접원가 | `costing`(ABC 배부·진료과 원가) | 재료·약품 등 직접비 차감 |
| 삭감 | `claims.ClaimAdjustment` | 순수입에서 삭감 반영 |
| 급여 명세 | `hr.PayrollLine`(item_code) | 성과급 = INCENTIVE 라인 반영(P3 엔진) |
| 고용형태 | P1 `employment_type` | 의료진 계약(CONTRACT/REGULAR) 위 개별계약 |

> **핵심**: 담당의(doctor_id)·수납·원가·삭감 데이터가 ERP에 있어 **의사별 순수입 집계가 ERP 내 가능**.
> 단 HIS 수납 동기화에 **담당의 포함 여부 검증 필요**(§9 전제).

## 3. 두 축

```
A. 의료진 계약 관리 (개별·별도)  ──→  계약별 성과급 산식·조건 정의
                                         │
B. 성과급 계산·등록·관리  ←── 진료실적(수납−직접원가−삭감) × 계약 산식
```

## 4. A. 의료진 계약 관리 (MedicalStaffContract — 별도)

- **계약 단위**: 의사 1인 × 계약기간(temporal, 갱신 이력). employment_type 위의 **개별 조건**.
- **계약 항목**:
  - 기본급(연봉/월), 진료수당, 당직 조건/단가, 전속/비전속
  - **성과급 산식**(유형 + 파라미터): 방식·배분율·기준금액·상·하한
  - 인정/제외 항목(비급여 포함 여부, 삭감 차감 여부)
  - 계약기간·갱신·종료
- **버전 관리**: 계약 개정 시 신규 버전(이력 보존) — 과거 정산 재현.

## 5. B. 성과급 계산

```
의사별 순수입 = Σ(수납액 by doctor_id) − 직접원가(재료·약품·ABC) − 삭감액
            → 계약 성과급 산식 적용 → 성과급액 → (상·하한·목표) 조정
            → 등록(월/분기) → 승인 → PayrollLine(INCENTIVE) 반영
```

## 5.5 실적 기준 정정 — '수납액' → '총진료수익(발생주의)' ★ (검토 보완)

> **초안의 '수납액 by doctor' 정의는 과소·부정확**. 의료수익 구조상 보정 필요:

- **수납액(Payment)은 본인부담금만** — 진료수익 = **본인부담 + 공단부담(청구)**. 수납만 쓰면 실적이
  보험비중만큼 과소 → **청구 기반(ClaimStatement)** 으로 총진료수익을 잡아야.
- **현금주의 vs 발생주의**: 수납(현금주의)은 미수·분할로 의사 귀속 왜곡. 성과급 실적은 **발생주의(진료
  발생=청구 산정 시점)** 권장. 단 미청구·미수 리스크는 별도.
- **정정된 순수입 정의**:
  ```
  총진료수익(by doctor) = Σ청구액(본인부담+공단, 발생주의)  [+ 비급여수익 §12]
  순수입 = 총진료수익 − 직접원가(재료·약품·ABC) − 확정삭감
  ```
- Reception.doctor_id는 **귀속 키**로 유지하되, 금액은 청구(ClaimStatement)·비급여에서. 수납은 미수
  관리·현금 분석 보조.

## 6. 성과급 산식 유형 (계약별 선택)

| 유형 | 산식 | 비고 |
|------|------|------|
| **순수입 배분(NET_COLLECTION)** | (수납−직접원가−삭감) × 배분율% | 가장 일반적 |
| **진료과 수익배분(DEPT_SHARE)** | 진료과 순이익 × 의사 기여율 | 팀 단위 |
| **목표 초과(TARGET_EXCESS)** | (실적−목표) × 율, 음수 0 | 인센티브형 |
| **RVU(상대가치)** | Σ(행위 RVU) × 단가 | 행위량 기반(수가 마스터 연계) |

> 1차는 **NET_COLLECTION**(데이터 가장 확실) 중심, 나머지는 확장.

## 6.5 수익 귀속 규칙 ★ (검토 보완)

> 단순 `doctor_id` 귀속은 공동진료·검사에서 왜곡 — 귀속 규칙 필요:

- **협진·공동진료**: 한 에피소드에 주치의 + 협진의 → 분할 귀속(주 70/협진 30 등 규칙) 또는 행위별.
- **검사·영상·판독**: 처방의 vs **판독의(영상의학·진단검사)** — 행위 유형별 귀속 의사 분리(처방 수익 ≠
  판독 수익).
- **수술**: 집도의·보조의 배분.
- **귀속 매핑**: 행위코드(수가) → 귀속 유형(처방/시행/판독) → 의사. 미매핑은 '진료과 공통'으로 풀링.
- 1차는 **주담당의 단일 귀속**(단순)으로 시작, 분할 귀속은 규칙 테이블로 확장.

## 7. 등록·승인 워크플로

```
산정(자동, 월/분기) → 검토(원무·기획) → 승인(경영진, 다단계) → 확정 → PayrollLine 반영
```
- 각 단계 **근거 스냅샷**(실적·원가·산식·결과) 보존 → 감사·이의 대응.
- 확정 전 수정 가능, 확정 후 정정은 역분개식 보정 레코드.

### 7.5 회계·세무 통합 ★ (검토 보완)
- **인건비 비용 인식**: 성과급 확정 시 **미지급비용 전표**(성과급비용/미지급금) — 발생주의(산정월) vs
  지급월 분리. costing 인건비·진료과 손익에 반영(BI 일관).
- **원천징수**: 성과급은 근로소득 → **4대보험·소득세 재계산**(P3 엔진에 INCENTIVE 포함 gross로).
  성과급만 별도 지급 시 상여 세액 처리. 누락 시 세무 리스크.
- **예산 연동**: 진료과 인건비 예산·손익과 대사.

### 7.6 소급 정정 (삭감 claw-back) ★ (검토 보완)
- **삭감은 진료 수개월 후 통보** → 이미 지급한 성과급의 사후 조정 필요. 산정 시 **확정삭감만** 반영하고,
  추후 삭감 확정 시 **차기 성과급에서 차감(claw-back) 또는 보정 레코드**.
- 정책: 환수 vs 차기 상계 — 노무 합의. 소급 한도·시효 명시.

## 8. 관리 화면

- **계약**: 의료진 계약 목록·상세(산식·기간)·갱신
- **실적 대시보드**: 의사별 순수입·성과급 추이(BI·costing 연계)
- **성과급 산정**: 기간별 산정·검토·승인 큐, 명세 반영 현황
- **권한**: 성과급은 민감 → 전용 RBAC(경영·기획만)·접속기록

## 11.5 예산·상한 통제 ★ (검토 보완)
- 성과급 총액이 진료과 수익성·인건비 예산을 넘지 않도록 **상한·예산 연동**(계약 cap + 진료과 풀 한도).
- 전월/전년 대비 **이상치 검증**·시뮬레이션(계약 변경 전 영향 추정).
