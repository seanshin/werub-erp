# 의료진·직원 직종 분리 + 직종·고용형태별 급여 체계 기획서

> **요약**: 의료기관 특성상 **의료진(의사·전공의·간호사·의료기사·약사)** 과 **일반직(행정·시설·경비 등)**,
> 그리고 **고용형태(정규·계약·일용·임시·감시단속)** 를 별도 관리하고, **급여 계산을 직종 × 고용형태별로
> 분리**한다. 현 단일 `job_group`·균일 4대보험·자유입력 명세를 **2축 분류 + 급여 규칙엔진**으로 확장.
> **작성일**: 2026-06-09 · **버전 v1.1**(SoT 분리 반영) · **상태**: 기획(협의) · **우선순위**: High(의료
> 기관 필수) · **연관**: FR-07 급여, FR-45 근무표, hr.statutory, duty_service, **D-2 인사 SoT**

> **v1.1 핵심 결정(SoT 역할분리 — D-2 확정)**: **HIS = 의료진 + 정규직 인사 마스터**(ERP는 `staff.*`
> 웹훅으로 **미러·읽기전용**), **ERP = 그 외 비정규 직군(계약·일용·임시·경비 등) 인사 마스터**(ERP에서
> 직접 CRUD). 즉 ERP HR의 **직접 관리 대상은 비정규/주변 인력**이고, 의료진·정규직은 HIS 발신을 받아
> 급여·회계 목적으로 보유. §3.5 참조.

---

## 1. 배경 / 요구

- 의료기관은 **의료진과 일반직의 관리·급여 체계가 본질적으로 다르다**:
  - 의료진: 면허·진료과·당직·교대·성과(진료실적) 연동 → 수당 구조 복잡
  - 일반직: 호봉·직책 중심
- 또한 **고용형태가 다양**: 정규직 외 **계약직·일용직·임시직·경비(감시단속적 근로)** 등 →
  **급여 계산·4대보험·근로시간 규제가 형태별로 상이**.
- 요구: ① 의료진/일반직 **별도 관리**(분류·화면·명세) ② **급여계산 별도**(직종·고용형태별 규칙).

## 2. 현황 (ERP) 와 공백

| 영역 | 현재 | 공백 |
|------|------|------|
| 직종 | `Employee.job_group` 5종(NURSE·DOCTOR·RESIDENT·TECH·STAFF) | 의료기사 세분·약사·경비/시설 직군 부재, 직군(의료/일반) 상위 구분 없음 |
| **고용형태** | **없음** | 정규·계약·일용·임시·감시단속 구분 불가 → 급여·보험·규제 분기 불가 |
| 급여 | `PayrollRecord/PayrollLine`(수당 **자유 입력**) | 직종·형태별 **자동 계산 규칙 없음** |
| 4대보험 | `statutory.insurance` **보수월액 균일** | **일용직 특례**(국민연금·건강 적용기준 월8일/60h, 일용 소득세 분리과세, 고용·산재만) 미반영 |
| 노동규제 | `duty_service` job_group 분기(전공의 80h·일반 52h) | 고용형태 특례(감시단속 근로시간 적용제외) 미반영 |

## 3. 핵심 — 2축 분류 모델

```
직종(job_category)  ┐
                    ├─→ 직교(orthogonal). 예: "계약직 간호사", "일용직 경비", "정규직 의사"
고용형태(employment_type) ┘
```

- **직군(staff_class)**: `MEDICAL`(의료직) / `SUPPORT`(일반직) — 최상위 관리 분리 축.
- **직종(job_category)**: 직군 하위 세부.
- **고용형태(employment_type)**: 급여·보험·규제 계산 분기 축.

## 3.5 SoT 역할분리 (D-2 확정) ★

```
┌──────────────────────────────┬───────────────────────────────────────────────┐
│ HIS 관리 (인사 마스터 SoT)    │ ERP 관리 (인사 마스터 SoT)                     │
├──────────────────────────────┼───────────────────────────────────────────────┤
│ • 의료진(의사·전공의·간호사·  │ • 비정규 직군: 계약직·일용직·임시직            │
│   의료기사·약사)              │ • 경비·시설·미화 등 주변/외주성 인력          │
│ • 정규직(일반정규 포함)       │ • (HIS 미등록 인력 전반)                       │
│ → ERP는 staff.* 웹훅 미러      │ → ERP에서 직접 채용·발령·직종·고용형태 CRUD    │
│   (읽기전용, 수정은 HIS에서)   │                                                │
└──────────────────────────────┴───────────────────────────────────────────────┘
```

- **Employee.source(managed_by)** 추가: `HIS`(미러·읽기전용) / `ERP`(직접 관리).
- **consumer 규약**: `staff.*` 인박스 consumer는 **source=HIS만** upsert. **source=ERP 직원은 절대
  덮어쓰지 않음**(ERP 고유). 역으로 ERP CRUD는 source=HIS 직원 수정 차단(읽기전용 미러).
- **급여**: ERP는 회계·급여 시스템 → 비정규(ERP 관리) 급여는 ERP가 **전권**. 의료진·정규직(HIS 관리)
  급여 계산을 ERP가 하는지/HIS가 하는지는 **결정 필요**(§9) — 인사 마스터 SoT(HIS)와 급여 계산 주체는
  분리될 수 있음.
- 이 분리로 **중복 관리·충돌 제거**: HIS는 핵심 상용 인력, ERP는 계약/일용/경비 등 ERP가 더 잘 다루는
  유연 인력. 기존 `staff.*` consumer(PR #58)가 HIS측 동기화 경로.

## 4. 직종 체계 (제안)

| 직군 | 직종(job_category) |
|------|-------------------|
| **의료직(MEDICAL)** | 의사(DOCTOR)·전공의(RESIDENT)·간호사(NURSE)·간호조무사(NURSE_AIDE)·약사(PHARMACIST)·의료기사: 방사선사(RADIOTECH)·임상병리사(LABTECH)·물리치료사(PHYSIOTHERAPIST)·작업치료사·치위생사 등 |
| **일반직(SUPPORT)** | 행정(ADMIN)·전산(IT)·시설(FACILITY)·경비(SECURITY)·영양/조리(NUTRITION)·운전(DRIVER) |

> 기존 `job_group`은 노동규제 분기(전공의법 등)에 쓰이므로 **유지**하되, 상위 `staff_class`와 세부
> `job_category`를 추가(하위호환). RESIDENT 등 규제 분기 키는 보존.

## 5. 고용형태별 급여·4대보험·근로 특례

| 고용형태 | 급여 | 4대보험 | 근로시간 |
|----------|------|---------|---------|
| **정규직(REGULAR)** | 월급제 | 4대 전부 + 퇴직금 | 주52h·전공의 80h |
| **계약직(CONTRACT)** | 월급제·계약기간 | 4대 전부 + 퇴직금(1년↑) | 정규 동일 |
| **일용직(DAILY)** | **일당제** | **일용 특례**: 국민연금·건강 = 월 8일/60h↑ 시만, 고용·산재 적용, **일용 소득세 분리과세**(일 15만 공제·6%·소액부징수) | 일 단위 |
| **임시/단시간(TEMP)** | 시급·기간제 | 소정근로시간 비례 | 단시간 보호 |
| **감시단속(경비, WATCH)** | 월급제·**근로시간 적용제외**(고용부 승인) | 4대 전부 | **주52h·연장가산 특례** |

→ `statutory`를 **고용형태 파라미터화**(일용 소득세·보험 적용기준 분기).

## 6. 직종별 수당 체계 (급여 분리)

| 직종 | 수당 구성(예) |
|------|--------------|
| **의사** | 기본급 + 진료수당 + **당직비** + **성과급**(진료실적/순수금 연동 — 청구·원가 데이터) |
| **전공의** | 기본급 + 당직비 (80h 규제 연동) |
| **간호사** | 기본급 + **야간·교대수당** + 간호등급 연동 + 위험수당 |
| **의료기사** | 기본급 + **자격수당** + 특수업무수당(방사선 등) |
| **약사** | 기본급 + 자격수당 |
| **일반직** | 기본급(호봉) + 직책수당 |
| **경비/시설** | 기본급 + 감시단속 수당 |

→ **급여 규칙셋(PayrollRuleSet)**: (직종 × 고용형태) → 수당 항목·계산식 템플릿. PayrollService가
명세(PayrollLine) **자동 생성** + 수기 보정 허용.

## 7. 모델 / 구현 방향

- **Employee 확장**: `source`(HIS/ERP — SoT §3.5), `staff_class`(MEDICAL/SUPPORT),
  `job_category`(세부직종), `employment_type`, 계약직 `contract_start/end`, 일용 `daily_wage`.
  (job_group 유지 — 규제 하위호환)
- **SoT 가드**: `staff.*` consumer는 source=HIS만 upsert / ERP CRUD는 source=ERP만 수정(§3.5).
- **PayrollRuleSet**(신규): 직종·고용형태별 수당 항목 정의 → PayrollService 자동 명세.
- **statutory 파라미터화**: `insurance(..., employment_type)` — 일용 특례 분기. 일용 소득세 함수 추가.
- **duty_service**: 감시단속 적용제외 분기 추가.
- **관리 화면 분리**: 의료진/일반직 별도 리스트·명세 탭, 직종·고용형태 필터.
