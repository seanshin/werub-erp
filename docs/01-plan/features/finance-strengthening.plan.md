# 재무회계 강화 기획서 (통제·관리회계·완결성)

> **요약**: 현 재무 모듈은 전표→재무제표·자산·채권채무·예산·리스·세금계산서·마감까지 **기록·집계**가
> 광범위(design v0.5 §12). 그러나 **① 재무제표 완결성(현금흐름표 미완) ② 내부통제(전표 승인 워크플로
> 부재) ③ 관리회계(예실대비·재무비율·원가연계) ④ 결산 완결성(마감 체크리스트)** 에 갭이 있다.
> 본 기획은 **새 도메인 추가가 아니라 기존 자산 위 강화**로, 의료기관 재무의 신뢰성·의사결정 가치를 높인다.
>
> **작성일**: 2026-06-15 · **버전**: v0.1(기획·협의) · **상태**: 기획 · **우선순위**: High(내부통제·결산 신뢰성)
> **연관**: design v0.5 §12.1(재무 심화), FR-49(전표 단일창구), FR-54(마감 후 역분개),
> finance-expansion-milestone.report, costing(ABC), analytics(BI)

---

## 1. 배경 / 문제

- **기록은 강하나 통제·완결성에 갭**: 복식부기 전표(멱등·역분개)·시산표·손익·재무상태표·자본변동표·
  고정자산(감가/처분/손상/재평가)·채권채무(aging)·예산(약정/집행)·전자세금계산서·기간마감·리스까지 구현.
  대부분 전표가 **타 모듈 이벤트로 자동생성**(F1 수납·청구·구매·급여)되어 정합성은 높다.
- **그러나 의료기관 재무가 외부(회계법인·세무·이사회·평가원)에 신뢰를 받으려면** 다음이 부족:
  1. **4대 재무제표 미완** — 현금흐름표가 정식(영업/투자/재무 3분류)이 아니라 현금계정 유입·유출
     집계(자금수지)에 그침. 외부 제출용 재무제표 세트 불완전.
  2. **내부통제(분개 승인) 부재** — Voucher 상태가 `POSTED|REVERSED`뿐. **수동 전표·역분개·결산분개가
     즉시 POSTED** — 작성자=승인자(maker-checker 분리 없음). 감사·횡령방지·오기 통제 취약.
  3. **관리회계 약함** — 예산집행(execution)은 있으나 **예실대비 차이분석(variance)·진료과별 손익·
     재무비율·공헌이익**이 부분적. 경영 의사결정용 레이어 미성숙.
  4. **결산 완결성** — 기간 마감은 있으나 **마감 전 점검(미결/미배부/감가누락/기간귀속)·재무제표 일괄
     산출·확정 스냅샷**이 수작업.

→ 본 기획은 이 4축을 **기존 서비스 재사용**으로 강화한다(신규 스키마 최소화).

## 4. 목표 / 범위

**목표**: 의료기관 재무를 **(1) 외부 신뢰(완전한 재무제표) (2) 내부통제(승인·감사) (3) 경영 의사결정
(관리회계)** 세 관점에서 신뢰 가능한 수준으로 강화한다.

**범위(1차)**: G-1~G-3(완결성·통제) + G-4~G-6(관리회계). 기존 전표·계정·마감 인프라 재사용.
**비범위(외부 의존·후순위)**: G-7 부가세/법인세 신고(세무사·회계법인 협의 — §8), 외화/연결재무제표(해당 없음),
실시간 원가(동인 실데이터 의존).

## 5. 핵심 기능 (강화 항목)

### P0 — 완결성·내부통제 (내부에서 흐름, 즉시 가치)

#### ① 현금흐름표(간접법) 정식화 — 4대 재무제표 완성 (G-1)
- `statements.cash_flow_statement(fiscal_year/기간)`: **영업/투자/재무 3분류**, 간접법
  (당기순이익 + 비현금항목[감가·충당] ± 운전자본 증감[매출채권·매입채무·재고]).
- 계정 kind·계정코드 → 활동분류 매핑 테이블(시드). 기존 `cash_flow`(자금수지)는 **자금일보**로 유지·분리.
- 출력: 화면 `/erp/finance-statements`에 탭 추가 + xlsx. 재무상태표 기말현금과 **정합 자가검증**
  (재무제표 balanced 검증 패턴 재사용).

#### ② 전표 승인 워크플로 (maker-checker) (G-2)
- Voucher 상태 확장: `DRAFT → PENDING → APPROVED(=POSTED) | REJECTED`(+기존 REVERSED). 마이그 1건.
- **적용 범위(선별)**: **수동 전표·역분개·결산분개**만 승인 대상(자동생성 F1 전표는 기존대로 즉시 POSTED —
  원천 통제 존재). 임계금액 이상만 승인 요구하는 정책값(옵트인) 고려.
- 작성자≠승인자 강제(SoD), 승인/반려 감사로그(`AUTO_*` 패턴 재사용), 알림(`notifications`).
- **미승인 전표는 재무제표·마감 집계서 제외**(POSTED만 집계 — 정합 보장).

#### ③ 결산 마감 체크리스트 + 확정 스냅샷 (G-3)
- `period_service.close` 전 **점검 규칙 실행**: 미결(DRAFT/PENDING) 전표·당월 감가 미계상·미배부 원가·
  기간귀속 오류·차대 불일치·미매칭 세금계산서 → 경고 목록 반환(차단 옵션).
- 마감 확정 시 **재무제표 스냅샷 저장**(시산표·손익·재무상태표·현금흐름표 확정본) — 사후 변경 대비 감사.

### P1 — 관리회계 (경영 의사결정)

#### ④ 예산 대비 실적(BvA) 차이분석 (G-4)
- 진료과·계정별 **예산 vs 약정 vs 집행 vs 차이(variance %)** + 월추세, 초과 경고 알림.
- 화면: 예산 대시보드(차트 — 기존 경량 SVG charts.tsx 재사용).

#### ⑤ 재무비율·경영 KPI 대시보드 (G-5)
- 표준 비율: 유동비율·당좌비율·부채비율·자기자본비율·**의료수익의료이익률·인건비율·재료비율**(의료기관 특화).
- 전기 대비·추세. analytics overview 확장.

#### ⑥ 원가-재무 통합 — 공헌이익·진료과 수익성 (G-6)
- ABC 배부 결과 ↔ 부서손익 정합, **진료과별 공헌이익(수익−변동원가)**·손익분기 분석.
- 원가 동인 실데이터 의존분은 폴백 유지(기존 abc_service 패턴).

### P2 — 세무·확장 (외부 의존)
- ⑦ 부가세 신고서·법인세 추정 보조(세무사 협의 — §8), 반복전표 자동화, 계정과목(COA) 관리 화면.

## 9. 평가지표 / 완료기준

- **재무제표 완전성**: 4대 재무제표 산출 + 현금흐름표 기말현금 = 재무상태표 현금(자가검증 통과).
- **내부통제**: 수동/역분개/결산 전표 100% 승인 경유, 작성자≠승인자, 감사로그 완비, 미승인=집계제외.
- **결산 신뢰성**: 마감 전 점검 자동 실행, 확정 스냅샷 보존, 마감 후 무단변경 0.
- **관리회계 활용**: 진료과별 예실대비·공헌이익·재무비율 대시보드 운영.
- **테스트**: 각 기능 재무 정합 자가검증 포함, CI 그린 유지.
