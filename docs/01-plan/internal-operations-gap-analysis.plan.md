# 의료기관 내부 운영 ERP — 갭 분석 & 보완 로드맵 (2026-07-20)

> 4개 도메인(재무·자금·예산 / 조달·재고·계약·경비 / HR·교육·평가 / 원무·수익·부대사업·문서결재) **병렬
> 갭 감사** 결과. 성숙한 ERP라 남은 것은 **주변부 얇음 + 명백한 공백 소수 + 확인된 미작동 버그 2건**.
> 각 항목 코드 근거로 판정(라벨만 vs 실제 depth 구분). Tier 0은 v1.171에서 완료.

| 결함 | 근거 | 조치 |
|---|---|---|

## Tier 1 — 완전 부재 · 병원 내부 운영 필수

| 갭 | 근거(무결과 grep 등) | 중요도 | 규모 |
|---|---|---|---|
| **지출·경비 관리**(경비정산+법인카드) | `expense`/`reimburse`/`corporate_card`/`법인카드` 전범위 grep 0건. 재무·조달 두 감사 독립 수렴 | 상 | 중~대 |
| **일반 전자결재/기안문서** | `approval_engine` doc_type이 PO·계약·전표 등 구조화 레코드에만 바인딩·자유형식 품의/공람 엔티티 없음 | 상 | 중(엔진 재사용) |
| **부대사업 수익** | 주차·임대·비보험검진 등 의료외수익 계정/모델/라우터 전무(4110·4120·46xx만) | 상 | 중~대 |
| **입고 검수·반품(RMA)** | `StockMovement` 타입 IN/OUT/DISPOSE/ADJUST뿐·RETURN 없음·`receive()`는 수량 3-way만 | 중~상 | 중 |

## Tier 3 — 신규 도메인(규모 대·기관 정책 의존)

## 권고 진행 순서

1. **Tier 0**(✅ 완료) — 미작동 버그.
2. **Tier 2 quick win 묶음** — 예산초과 경보·면허 보수교육·수납원별 마감·환자 미수 독촉(저비용·고효과).
3. **Tier 1 지출·경비 관리** — 완전 부재·수렴·재사용 자산 많음(Attachment·ApprovalEngine).
4. **Tier 1 일반 전자결재** — 엔진 재사용으로 규모 유리.
5. 이후 부대사업 수익·RMA·위탁재고·Tier 3(기관 정책 확인 후).
