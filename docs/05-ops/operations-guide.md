# ERP 운영 가이드 (월마감·결산·연동)

> 대상: 재무·인사·자재 담당자·관리자. 정기 운영 절차와 연동 점검을 정리.
> 화면 경로는 좌측 메뉴 기준. 권한: 대부분 ADMIN/DIRECTOR, 일부 부서장(MANAGER).

## 1. 월마감 루틴 (매월 초)

| 순서 | 작업 | 화면 | 비고 |
|:---:|------|------|------|
| 1 | 전월 수납·청구·구매 전표 마감 확인 | 재무 → 전표·예산 | 누락분 입력 |
| 2 | **월마감 일괄 실행** | 재무 → 기간 마감 → "월마감 일괄" | 감가상각·퇴직급여충당·리스 회계 일괄(멱등, 재실행 안전) |
| 3 | 재무제표 확인 | 재무 → 결산·재무제표 | **자산=부채+자본 균형** 확인 |
| 4 | **기간 마감(잠금)** | 재무 → 기간 마감 → "기간 마감" | 마감 후 해당 월 전표 생성 차단 |
| 5 | 경영 KPI 점검 | **경영진 대시보드** | 재무·자금·청구·재고·자산 한눈에 |

- **정정 필요 시**: 마감된 기간은 직접 전기 불가 → **역분개**(현재 개방월 전기) 또는 기간 **재개방** 후 수정.
- 월마감은 **멱등** — 중복 실행해도 이중 전표 없음(감가/충당/리스 각 기간 UNIQUE).

## 2. 연말 결산 (회계연도 종료)

| 순서 | 작업 | 화면 |
|:---:|------|------|
| 1 | 12월 월마감·기간마감 완료 | 재무 → 기간 마감 |
| 2 | **연말 결산분개** | 재무 → 기간 마감 → "연말 결산"(연도 입력) |
| — | 손익(수익·비용) → **이익잉여금(3300)** 이전. 연도별 1전표 멱등 | |

## 3. 자금 관리

- **자금수지 예측**(재무 → 자금수지 예측): 현금잔액 + AR 수금예정·AP 지급예정 → 월별 포지션. **최저잔액 < 0** 경보 시 수금 촉진/지급 조정.
- 채권·채무·자금(재무 → 채권·채무·자금): AR/AP 연령분석·실적 자금수지.

## 4. 자재 관리

- **재고 평가·안전재고**(재고 → 재고 평가·안전재고): 재고자산 평가액·미달 품목·**재고회전율/장기재고**.
- **재고 실사**(재고 → 재고 실사): 실재고 입력 → 차이 → 반영(감모손실/조정이익 전표).
  - 주의: 입고 시 매입단가가 로트에 보존돼야 평가액 산정(과거 로트는 단가 누락 표시).

## 5. 인사·급여

- **급여**(인사 → 급여): 월 급여 생성·명세.
- **퇴직급여충당**(인사 → 퇴직급여충당): 월별 충당 전입. DB형=충당부채, **DC형=부담금**(미지급) 자동 분기.
- 월마감 일괄에 퇴직급여충당이 포함되므로 별도 실행 불요(개별 확인용).

## 6. 고정자산 (재무 → 고정자산)

자산 6대 사건: **취득 → 감가상각(월마감 자동) → 손상 → 재평가 → 처분 → 리스**.
- 손상: 회수가능액 < 장부가 시 "손상" 버튼.
- 재평가: 공정가치 입력 "재평가"(증가=재평가잉여금/감소=손실).
- 리스(재무 → 리스): 개시(현가 인식) → 월 회계(이자·원금·상각).

## 7. HIS·AI 연동 점검 (관리자)

- **연동 관리화면**(관리 → 연동): 설정상태·HIS 인박스 모니터(시크릿 비노출).
- HIS 웹훅: materials·finance·assets·hr·procurement 도메인 consumer 자동 처리. 실패건 FAILED 가시화 → 재처리.
- AI 사전심사(의료보험 → 사전심사): 공시 검색·삭감위험 평가(weve). 실 고시 적재는 `scripts/import_notices.py`.

## 8. 운영 점검 (개발/배포)

- 신규 API는 **라우트 스모크 테스트**(`tests/test_route_smoke.py`)·**HTTP 인증 200 검증** 필수 — 라우터 prefix 중복·RBAC 정책 누락 결함 방지([메모리: ERP 엔드포인트 검증]).
- 마이그레이션: `alembic upgrade head`(rebuild 후 실행). head **0032**.
- 회계 정합: 모든 전표는 VoucherService 단일 창구(차대 균형·멱등). 재무상태표 `balanced` 상시 확인.

## 9. 진료비 본인부담 정책 (원무)

### 9.1 본인부담금 10원 절사 (건보 시행령 §19)
- **급여 본인부담금은 10원 미만 절사(버림)** — 예: 급여 총액 12,340원 × 40% = 4,936원 → **4,930원** 청구.
- **비급여는 절사 안 함**(전액 본인부담). 급여분(총 본인부담 − 비급여)에만 적용.
- **절사분(최대 9원)은 보험자 부담** — insurer_share가 흡수(총액 = 본인부담 + 보험자 불변).
- 설정: `patient_copay_round_unit`(기본 **10**). `1`이면 절사 없음(정액제 기관 등 예외 시).
- 노출: 진료비 조회(invoice) 응답에 `patient_share`(절사 후)·`patient_share_raw`(절사 전)·`copay_rounding`(절사액) 포함 — 원무 화면·명세에서 "본인부담 X원(10원절사 −Y)"로 안내.

### 9.2 발생주의(미수금) 전환 절차 — 회계사 사인오프 후
현행 **현금주의**(수납시점 수익)이며, 발생주의(진료시점 DR 1131/CR 4110) 전환은 아래 순서로:
1. 회계사 사인오프 + **기준월(cutover) 확정**.
2. `patient_accrual_cutover_month = YYYY-MM` 설정.
3. **개통 1회 실행**: `POST /patients/accrual/open-cutover?cutover_month=YYYY-MM` — 기준월 이전 미수납분을 DR1131/CR4110로 당기 인식(멱등). 이미 수납분은 불건드림.
4. `patient_accrual_enabled = true`. 이후 진료시점 발생·수납시점 1131 상계·야간 잡 `POST /patients/accrual/run`.
- 기준월 이전 진료분은 accrue 제외(현금주의로 이미 인식 — 이중계상 방지).

## 10. 공식 문서 발급기관 표기 (총무)

### 10.1 기관 설정 관리화면 (권장)
- **시스템 → 기관 설정**(`/erp/admin/org`)에서 ADMIN이 기관 정식명칭·대표자·사업자등록번호·요양기관기호·주소·전화를 설정 — 저장 즉시 재직/경력증명서·계약서(안)·급여명세서 PDF에 반영(재기동 불요).
- 증명서 하단은 기관장 명의 관행에 따라 `{기관명}장`으로 표기(예: "OO의료재단 OO병원" → "OO의료재단 OO병원장").
- **미설정 시 폴백**: 증명서 "본 의료기관장", 계약서 발주자 "본 의료기관" — 견본 문구("OO병원장")는 출력되지 않음.
- ⚠ 요양기관기호는 문서 표기용 — HIS/그룹웨어 연동 식별자(`hospital_code`)는 `.env`로 별도 관리(변경 금지).

### 10.2 환경변수 폴백 (ORG_NAME)
- DB 설정이 없을 때만 `.env ORG_NAME`이 폴백으로 쓰임(우선순위: **DB > env > 폴백 문구**). env 변경은 core 재기동 필요.
