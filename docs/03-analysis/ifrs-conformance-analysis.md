# 회계 IFRS(K-IFRS) 부합도 분석서

> **요약(최종)**: P0~P3 정합 강화 완료(2026-06-22, PR #370~#386·마이그 0087~0101). 거래 기록·정산 엔진(복식부기·
> 멱등·역분개·Maker-Checker·기간잠금)에 더해, **기말 측정·결산조정**(대손충당·이연법인세·재고저가법·퇴직 보험수리·
> 외화환산·발생주의 수익)과 **표시·공시**(포괄손익 2단·주석 정량/등록·영업부문·공정가치 서열·중간보고·전기비교)를
> 전부 구현. 모든 조정은 결산분개(전표)로 귀결·역분개 가능하며, 항목별 인증 5종 문서(`docs/06-compliance/ifrs/`)를 보유.
>
> **종합 부합도: 약 95%+ 달성** (초기 ~65% → P0 80 → P1 88 → P2 93 → P3 96). 잔여 ~3~5%는 보험계리(완전 DBO)·
> 세무조정/이월결손·외부감사 의견 등 **소프트웨어 외 전문가 서명 영역**(SW 상한 ~95~97%).
> 남은 부분 부합(🟡): **1115 수익인식**(진행률 자동 산정 HIS 의존)·**1012 법인세**(당기법인세·세무조정 외부) — 모두 외부 의존.
>
> **작성일**: 2026-06-22 · **버전**: v1.0(최종) · **상태**: 완료 · **연관**: [ifrs-conformance.plan.md](../01-plan/features/ifrs-conformance.plan.md)

## 0. 적용 기준 전제 (중요)

- **법적 의무 기준**: 비영리 **의료법인**은 「의료기관 회계기준 규칙」(보건복지부령) 적용. 전면 **K-IFRS**는
  외부감사 대상(주식회사 등 외감법인·상장사) 기준이다. 본 분석은 요청대로 **K-IFRS/IFRS 잣대**로 평가했으며,
  실제 강제 적용 기준은 기관 형태(의료법인/영리/외감 여부)에 따라 달라질 수 있다.
- 따라서 본 분석의 "🔴 미흡"은 **법 위반이 아니라 IFRS 정합을 목표로 할 때의 갭**이다. 단계 적용 시
  기관의 실제 회계기준·외부감사 요구에 맞춰 범위를 조정한다.

## 2. 영역별 상세 (초기 진단 — 2026-06-22 착수 시점)

> ⚠️ 본 §2.2·2.3은 **착수 시점(부합도 ~65%)의 갭 진단**이며, P0~P3 구현으로 대부분 해소됨(§1 종합표가 현재 상태).
> 이력 보존을 위해 원문 유지.

### 2.1 ✅ 강한 영역 — 거래 인식·기표

- **복식부기 항등식**: 모든 전표 차변=대변 Decimal 정확 비교(`service.py:43`). 라인은 `account_code`
  문자열 참조(FK 아님) — 코드 변경 시 과거 집계 보존.
- **내부통제**: Maker-Checker(DRAFT→PENDING→POSTED, 작성자≠승인자 `service.py:112`), 역분개(원전표
  REVERSED 보존·반대분개 개방기간 전기·사유·감사로그), 기간 잠금(마감기간 전기 차단).
- **유형자산·리스·손상·재평가**: IAS 16/36, IFRS 16을 정공법으로 — 재평가잉여금(3400)·손상누계(1815)·
  사용권자산(1720)/리스부채(2210)·처분 시 재평가잉여금 실현까지 OCI 흐름 반영.
- **결산**: 마감 사전점검(미결전표·시산표 균형·감가누락·미배부원가·미매칭 세금계산서) + 4종 스냅샷 +
  연말 손익→이익잉여금(3300) 대체(멱등).

### 2.2 🟡 부분 — 측정·표시 보완 필요

- **재무제표 표시(1001)**: BS 유동/비유동은 코드 prefix(11/21)로 구분되나 **포괄손익계산서 형식**(당기손익+
  기타포괄손익 2단)·**주석**·기능별 비용구분 부재. 재평가잉여금 등 OCI는 자본엔 반영되나 손익 형식엔 미표시.
- **재고(1002)**: FIFO·실사 감모는 있으나 **저가법(min(원가, NRV))** 없음 → 진부·손상 재고 과대.
- **종업원급여(1019)**: 확정급여채무를 **할인율·임금상승률 반영 현가**가 아닌 명목 근속 기준으로 계상 →
  충당부채 측정 부정확. 보험수리적손익(OCI) 없음.
- **수익(1115)**: 수납(현금)시점 인식이 기본 → 진행기준·미청구수익·검진권 시효 인식 미흡(선수금 부채인식은 O).
- **환율(1021)**: 외화 분리계좌·외화GL Stage1 LIVE. 기말 외화환산·환산차손익·기능통화 명시 Stage2 대기.

### 2.3 🔴 미흡 — 측정 엔진 부재(외부 결산조정 의존)

- **이연법인세(1012)**: 충당부채·손상·감가·대손의 회계/세무 **일시적차이**를 DTA/DTL로 인식하지 않음 →
  손익이 세후로 정확히 표시되지 않음. 법인세비용·이월결손 추적 없음.
- **충당부채(1037)·대손/ECL(1109)**: 퇴직급여 외 충당 전무. 특히 **미수금 대손충당금** 없이 전액 자산 계상
  → 자산·자본 과대.
- **차입원가(1023)·무형자산(1038)**: 자본화·상각 모듈 없음(현재 차입·무형 거래 규모 미확인).
- **주석 공시**: 정형 구조 없음.
