# IFRS 인증·증빙 문서 체계 (Framework)

> 본 디렉터리는 회계 IFRS(K-IFRS) 정합 강화 작업의 **외부감사·내부회계관리제도(ICFR) 대응 증빙 패키지**를
> 코드 구현과 함께 누적한다. IFRS는 자체 발급 "인증서"가 없으며, **외부감사인의 감사의견**과 **ICFR 평가**로
> 적정성이 표명된다 — 따라서 본 문서들은 *감사·평가에 제출 가능한 증빙*이다.
>

## 1. 준거 기준 (인증 프레임워크)

| 축 | 기준 | ERP의 역할 |
|---|---|---|
| 회계기준 | K-IFRS(기업회계기준서) + (의료법인) 의료기관 회계기준 규칙 | 인식·측정·표시·공시 산출 |
| 감사기준 | 회계감사기준(K-ISA) | **감사증거(audit evidence)** 제공(전표·원장·스냅샷·재현절차) |
| 내부통제 | 내부회계관리제도(ICFR / K-SOX) | 통제활동 문서화·운영증적(승인 SoD·기간잠금·감사로그·결산 체크리스트) |
| 경영진 책임 | 재무제표 작성책임·표명 | 표명서(assertions/) 누적 |

> 주의: 비영리 의료법인의 강제 기준은 의료기관 회계기준일 수 있다. K-IFRS 정합은 옵션/병행이며, 외부감사·
> ICFR 평가 대상 여부는 기관 형태(외감법인·상장 등)에 따른다.

## 2. 항목별 5종 문서 세트

구현 항목(기획서 P0~P3) 1건마다 다음 5종을 산출한다:

1. **회계정책서** `policy/<std>-<topic>.md` — 인식·측정·표시 정책
2. **측정방법론서** `methodology/<std>-<topic>.md` — 산식·가정·데이터원천·예시·코드 file:line
3. **통제기술서** `controls/<std>-<topic>.md` — 통제활동·주체·주기·증적
4. **준수 체크리스트** `checklist/<std>-<topic>.md` — 기준서 요구사항 vs 구현 매핑
5. **테스트·운영 증빙** — 단위테스트명·결산 전/후 전표·스냅샷(증빙은 methodology/evidence 절에 인용)

## 3. 문서 규약

- 파일명: `<기준서번호>-<주제>.<종류>.md` (예: `1109-allowance.policy.md`).
- 모든 측정방법론서는 **구현 file:line·마이그레이션·테스트명**을 인용(코드↔문서 양방향 추적).
- 가정(할인율·세율·충당률·NRV) 값은 **설정 테이블 인용**(하드코딩 금지) + 개정이력.
- 상태: `초안(Draft) → 검토(Review) → 승인(Approved)`. 대장은 [status-register.md](status-register.md).

## 4. 감사 재현 절차(공통)

각 측정 항목 증빙은 다음 재현 절차를 포함한다(감사인 검증 가능):
1. 입력(잔액·가정) 확인 → 2. `GET .../preview` 조정액 산출 → 3. `POST .../post` 결산분개 전기 →
4. 재무제표 반영 확인 → 5. 필요 시 역분개(reverse)로 원복. 모든 단계는 감사로그(해시체인)에 기록.

## 5. 진행 상태

기준별 5종 문서 진행과 부합도 기여는 [status-register.md](status-register.md)에서 관리한다.
