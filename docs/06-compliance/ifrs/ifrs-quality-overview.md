## 3. 품질 보증 (Quality Assurance)
- **통제(ICFR)**: 항목별 통제기술서(controls/) — RBAC(write 권한)·멱등(source_ref)·전표 차대 균형·기간잠금(allow_closed)·Maker-Checker·감사로그.
- **측정 무결성**: 가정(할인율·대손율·세율·NRV·환율)은 설정값·시점관리, 결산 사전점검(preclose_check) 체크리스트 통합.
- **OCI 분리**: 재평가·보험수리 손익은 OCI(3400/3410)로 분리, 이연법인세는 P/L-origin만(OCI backwards tracing 제외 — 세무 전문).
- **테스트 증빙**: 항목별 pytest(멱등·차대균형·한도·경계). 품질점검(code-analyzer, PR #393) 보완 반영.
- **계정 충돌 방지**: 신규 계정은 **prod 빈코드 사전확인** 후 시드(ON CONFLICT DO NOTHING의 조용한 무시·downgrade 위험 회피). 핫픽스 이력: 5660→5690, 4630→4640.

## 4. 적용·반영 확인 경로 (How to Verify In-App)
1. **IFRS 플로팅 마크**(모든 화면 우측 하단): 그 화면에 적용된 기준 + 당해 처리 금액·건수.
2. **IFRS 정합 현황 화면**(`/finance-ifrs`): 전 기준 카탈로그·상태·당해 처리 활동(전표 집계)·각 화면 바로가기.
3. **결산분개 추적**: 각 처리는 전표(source_module: closing-ifrs·intangible·hr.retirement·disclosure 등)로 조회·역분개 가능.

## 5. 잔여·전제
- **전문가 영역(SW 외)**: 완전 DBO(사망/이직률·사외적립자산 — 보험계리사), 당기법인세·세무조정·이월결손(세무사), 감사의견(회계법인).
- **데이터 의존 백로그**: C-6 금융상품 공정가치 주석(IFRS 9), NRV 자동수집(외부 시세).
- **전제**: 비영리 의료법인은 의료기관 회계기준이 강제일 수 있어 K-IFRS 정합은 옵션/병행.
