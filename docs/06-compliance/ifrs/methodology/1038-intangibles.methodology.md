# 측정방법론서 — 무형자산·차입원가 (K-IFRS 1038·1023)

**상태**: Draft · **작성일**: 2026-06-22 · **구현**: `services/core/src/erp/finance/intangible_service.py`

## 1. 무형자산
- 취득: `차) 무형자산 1850 / 대) 현금 1110(또는 미지급 2110)`.
- 월 상각(정액): `(원가+자본화차입원가)/내용연수/12` → `차) 무형자산상각비 5215 / 대) 상각누계 1855`. 멱등(자산·기간).

## 2. 차입원가 자본화(1023)
- `차) 무형자산 1850 / 대) 미지급금 2110`(적격자산 원가 가산). 이후 상각 기준에 포함.

## 3. 손상·환입(K-IFRS 1036) — 2026-06-23 확장(마이그 0107)
- 장부가 = 원가+자본화차입원가 − 상각누계 − **손상누계**.
- 손상: 회수가능액 < 장부가 → `차) 무형자산손상차손 5216 / 대) 손상차손누계 1856`. 멱등(자산·일자).
- 환입: 회복분을 **손상누계 한도** 내 `차) 1856 / 대) 무형자산손상차손환입 4641`. 환입은 회수가능액 초과 불가
  (손상누계 한도가 상각후원가 초과 carrying을 자동 방지).

## 4. 처분(K-IFRS 1038) — 2026-06-23 확장
- `차) 상각누계 1855 + 손상누계 1856 + 현금 1110(처분가) [+ 처분손실 5616] / 대) 무형자산 1850(원가+자본화) [+ 처분이익 4615]`.
- 처분손익 = 처분가 − 장부가. status=DISPOSED·disposed_on 기록. 멱등(자산).

## 5. 엔드포인트
- `GET/POST /finance/intangibles`·`/amortize/{yyyymm}`·`/capitalize-borrowing`·`/impair`·`/reverse-impairment`·`/dispose`(finance.assets).

## 6. 예시 (테스트 근거)
- 소프트웨어 2,400만/5년 → 월상각 40만. 자체개발 1,000만+자본화차입 200만 → 월상각 20만.
- 손상: 장부가 1,000만 → 회수가능 700만 → 손상 300만(5216/1856). 환입: 회복 900만 → 환입 200만(회수가능 한도).
- 처분: 장부가 600만(손상 400만 후) → 처분가 700만 → 처분이익 100만, 차대 균형.
- 검증: `tests/test_intangibles.py::test_acquire_and_amortize`·`test_capitalize_borrowing`·
  `test_impair_reverse_and_book_value`·`test_dispose_with_gain`.
