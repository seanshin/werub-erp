# 측정방법론서 — 퇴직급여 DBO (K-IFRS 1019)

**상태**: Draft · **작성일**: 2026-06-22 · **구현**: `services/core/src/erp/hr/retirement_service.py`

## 1. 산식 (간이 PUC)
```
명목추계 = 평균임금 × (근속일수/365)                 # statutory.severance
n(잔여근속) = max(0, 정년 − 현재나이)                 # 생년월일 기반(미상 시 factor=1)
factor = ((1 + 임금상승률) / (1 + 할인율)) ^ n
DBO(직원) = 명목추계 × factor
재측정(OCI) = Σ DBO(DB형 재적) − 현재 충당부채(2120 대변잔액)
```
- 도출: 미래최종임금=현재×(1+g)^n, 과거근무귀속=최종임금×현재근속, 현가=÷(1+d)^n → 명목×((1+g)/(1+d))^n.
- 구현: `RetirementService.dbo_preview` / `dbo_post` / `_assumption` / `_provision_balance`.

## 2. 결산분개 (재측정 = OCI)
- DBO>명목(손실): `차) 보험수리적손익 3410(OCI) / 대) 퇴직급여충당부채 2120`; DBO<명목은 반대.
- 전표: `source_module="closing-ifrs"`, `source_ref="dbo-remeasure:{yyyymm}"`, 월말, `allow_closed`, 멱등.

## 3. 가정 / 데이터 원천
| 입력 | 원천 | 비고 |
|---|---|---|
| 평균임금 | payroll EARNING(최근월) | `_avg_wage` |
| 근속·나이 | Employee.hired_on·birth_date | 잔여근속 |
| 할인율·임금상승·정년 | `hr.actuarial_assumptions` | 설정·시점 |
| 현재 충당 | 계정 2120 원장 | 대변잔액 |

## 4. 예시 (테스트 근거)
- 평균임금 500만·근속 10년·잔여 15년, g3%/d4% → factor≈0.866 → DBO<명목, 재측정=DBO(명목충당 0 가정).
- 검증: `tests/test_actuarial_dbo.py::test_dbo_preview_discounts`, `::test_dbo_post_idempotent`.

3. 자본변동표·포괄손익에서 3410, BS에서 2120 반영 확인.
