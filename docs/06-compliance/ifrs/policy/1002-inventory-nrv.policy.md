# 회계정책서 — 재고자산 저가법·원가흐름 (K-IFRS 1002)

**기준**: 기업회계기준서 제1002호(재고자산) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 인식·측정
- 재고자산은 **취득원가와 순실현가능가치(NRV) 중 낮은 금액**으로 측정한다(저가법).
- 평가손실(취득원가 > NRV)은 재고자산평가충당금(1159, 자산 차감)으로 인식하고 재고자산평가손실(5540)을
  당기비용으로 인식한다. NRV 회복 시 최초 취득원가를 한도로 환입한다.
- **원가흐름**: 품목별 `cost_method`(FIFO 기본 / 가중평균 WAVG)로 관리한다. 출고원가는 FIFO 엔진이 결정하며,
  기말 재고 평가액은 로트별 잔량×매입단가의 합(가중평균단가 정보 병기).

## 2. NRV 결정
- NRV 단가(`scm.items.nrv_unit`)는 정상 영업과정의 예상 판매가에서 완성·판매 비용을 차감한 추정치로,
  관리자가 품목별로 입력한다. 미설정 품목은 취득원가를 유지(평가 제외).

## 3. 표시
- 재고자산평가충당금(1159)은 재무상태표에서 재고자산의 차감 표시. 평가손실(5540)은 손익.

## 4. 적용 한계 / 예외
- NRV는 **수기 입력**(시장가 자동수집 없음). 회전율·진부화 기반 자동 제안은 후속.
- 기말 재고 총평가액은 로트 잔량 기준이라 FIFO/WAVG 간 총액 차이가 없으며, 원가흐름 차이는 출고원가(COGS)에서
  발생한다(가중평균단가는 정보 제공).
