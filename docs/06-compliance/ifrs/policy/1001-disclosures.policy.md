# 회계정책서 — 재무제표 주석 (K-IFRS 1001)

**기준**: 기업회계기준서 제1001호(재무제표 표시) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 주석 구성
- **정량 주석(자동)**: 유형자산 증감표(취득·감가·처분·장부가, K-IFRS 1016), 충당부채·충당금 증감표
  (기초·전입·감소·기말, K-IFRS 1037). GL 계정 증감에서 산출.
- **정성 주석(수기)**: 주요 회계정책, 특수관계자, 우발부채, 보고기간후사건 등(payload 텍스트 편집).

## 2. 표시
- (period, note_key) 단위. 자동주석은 산출 시점 데이터, 정성주석은 저장본.

## 3. 적용 한계
- 자동주석은 유형자산·충당부채 2종부터. 리스 만기분석·금융상품·부문(P2)·특수관계자(P2)는 후속/정성.
- 주석 문구 자동작성이 아니라 데이터·골격 제공.
