# 회계정책서 — 자산손상 환입 (K-IFRS 1036)

**기준**: 기업회계기준서 제1036호(자산손상) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 인식·측정
- 과거 인식한 손상차손의 사유가 소멸·감소하면 **손상차손을 환입**한다(원가모형).
- 환입 한도: 손상을 인식하지 않았을 경우의 장부가액(취득원가−감가상각누계)을 초과할 수 없고, 인식한
  손상누계(1815) 범위 내. 환입액은 당기손익(손상차손환입 4640)으로 인식.

## 2. 표시
- 손상차손누계(1815) 차감, 손상차손환입(4640) 수익. 자산 장부가 회복.

## 3. 적용 한계
- 영업권 손상은 환입 불가(본 모듈 유형자산 한정). 재평가모형 자산의 환입은 OCI 처리(후속).

## 4. 변경 이력
