# 회계정책서 — 대손충당금 / 기대신용손실 (K-IFRS 1109·1037)

**기준**: 기업회계기준서 제1109호(금융상품) 기대신용손실 + 제1037호(충당부채) · **항목**: 매출채권(미수금) 대손
**상태**: Draft · **작성일**: 2026-06-22

## 1. 인식
- 매출채권(미수금, 계정 1130)에 대해 **기대신용손실(ECL)** 을 대손충당금(계정 1190, 자산 차감)으로 인식한다.
- 손실충당금 전입·환입은 당기손익(대손상각비 5690)으로 인식한다.

## 2. 측정
- **간이법(연령기반 충당 매트릭스)** 을 적용한다. 매출채권을 연체기간 버킷(current/1-30/31-60/61-90/90+)으로
  분류하고 버킷별 손실률을 곱해 충당액을 산정한다.
- 손실률은 설정 테이블(`finance.allowance_rates`)로 관리하며 관리자가 과거 손실경험·전망을 반영해 조정한다.
- 기본 손실률: current 0.5% · 1-30 2% · 31-60 10% · 61-90 30% · 90+ 50%.

## 3. 표시
- 대손충당금(1190)은 재무상태표에서 매출채권의 **차감 표시**(자산 kind, 대변잔액 → 자산 총계 감소).
- 대손상각비(5690)는 손익계산서 비용.

## 4. 적용 한계 / 예외
- 거시경제 전망을 반영한 **forward-looking 다중시나리오 ECL** 은 미적용(후속 과제). 본 정책은 단순화된
  실무적 간이법이며, 중요 채권·집중 위험은 개별 평가로 보완할 수 있다.
- 충당 산정 대상은 현재 매출채권(AR)에 한정. 기타 금융자산은 범위 외.
