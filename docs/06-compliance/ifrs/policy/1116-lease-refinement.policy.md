# 회계정책서 — 리스 정밀화 (K-IFRS 1116)

**기준**: 기업회계기준서 제1116호(리스) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 인식·측정
- 리스개시 시 사용권자산·리스부채(지급액 현가)를 인식하고 이자·상각을 월별 인식한다.
- **단기(≤12개월)·소액 리스 면제**: 사용권자산·리스부채를 인식하지 않고 리스료를 정액 비용(단기·소액리스료 5645)으로 인식한다(exempt).
- **리스변경 재측정**: 지급액·기간 변경 시 잔여기간 신지급액 현가로 리스부채를 재측정하고 사용권자산을 동액 조정한다.
- **만기분석 공시**: 리스부채의 잔여 지급액(미할인)을 만기버킷으로, 현재 부채(현가) 합을 주석 공시.

## 2. 적용 한계
- 재측정 시 잔여 상각은 조정된 사용권자산 기준 정액(상각 스케줄 정밀 재계산은 단순화).
- 변동리스료·리스인센티브·복구원가는 후속.
