# 회계정책서 — 공정가치 서열·중간보고·전기비교 (K-IFRS 1113·1034·1001)

**상태**: Draft · **작성일**: 2026-06-22

## 1. 공정가치 서열(1113)
- 공정가치로 측정하는 자산(재평가 유형자산)은 측정에 사용한 투입변수의 관측가능성에 따라 Level 1/2/3으로
  분류·공시한다. 기본 재평가는 Level 3(기업 추정), 관측가능 시장가 사용 시 상향.

## 2. 중간재무보고(1034)
- 분기 요약 손익·누적(YTD)·전년 동분기 비교를 제공한다(요약 형식).

## 3. 전기 비교표시(1001)
- 재무상태표를 당기말·전기말 2기로 비교 표시한다(손익은 전년 동기 비교 기존 제공).

## 4. 적용 한계
- 공정가치 서열은 유형자산 재평가 한정(금융상품 공정가치는 후속). 중간보고는 요약(주석 축약).
