# 회계정책서 — 이연법인세 (K-IFRS 1012)

**기준**: 기업회계기준서 제1012호(법인세) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 인식
- 자산·부채의 **장부금액과 세무기준액의 일시적차이**에 대해 이연법인세자산(1180)·이연법인세부채(2260)를
  인식한다. 이연법인세 변동은 당기손익(법인세비용 5810)으로 인식한다(자본·OCI 직접귀속 항목 제외 — 한계 참조).

## 2. 측정
- 일시적차이에 **보고기간말 유효세율**(설정 `finance.tax_rate_settings`)을 적용한다.
- **차감할 일시적차이**(충당부채·대손충당금·손상누계·재고평가충당금 등 손금 시점차이) → 이연법인세자산.
- **가산할 일시적차이**(재평가잉여금 등) → 이연법인세부채.
- 이연법인세자산은 실현가능성이 높은 범위에서 인식한다(본 기초 구현은 실현가능 가정 단순화 — 한계 참조).

## 3. 표시
- DTA(1180) 자산, DTL(2260) 부채, 법인세비용(5810) 손익. 연말(12/31) 측정·차액 결산분개.

## 4. 적용 한계 / 예외
- **단일 유효세율** 사용(한국 누진세율 9/19/21/24% 미반영). 관리자가 기관 유효세율을 설정.
- **당기법인세**(과세소득×세율)·세무조정·이월결손금공제는 **세무신고(외부) 영역** — 본 구현은 *이연*법인세
  측정에 한정. 법인세비용은 이연 부분만 반영.
- 재평가잉여금 관련 이연법인세의 OCI 직접귀속은 단순화(손익 경유) — 후속 정교화.
- **세무 전문가 검증 권장**.
