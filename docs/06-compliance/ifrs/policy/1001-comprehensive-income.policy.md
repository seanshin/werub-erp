# 회계정책서 — 포괄손익계산서·OCI 표시 (K-IFRS 1001)

**기준**: 기업회계기준서 제1001호(재무제표 표시) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 표시
- 경영성과를 **당기손익 + 기타포괄손익(OCI) = 총포괄손익** 2단 구조로 표시한다.
- OCI 구성: 재평가잉여금(3400) 변동, 확정급여 재측정요소(보험수리적손익 3410). 후속 당기손익 **미재분류** 항목.

## 2. 측정
- 표시 항목은 신규 측정이 아니라 기존 계정(유형자산 재평가·DBO 재측정)의 기간 순증감 집계.

## 3. 적용 한계
- OCI 항목은 현재 재평가잉여금·보험수리적손익 2종. 해외사업환산·현금흐름위험회피 등은 발생 시 확장.
- 비용 분류는 기능별/성격별 단일표시(기능별 매출원가 구분은 후속).

## 4. 변경 이력
