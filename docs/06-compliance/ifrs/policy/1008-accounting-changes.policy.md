# 회계정책서 — 회계정책·추정변경·오류 (K-IFRS 1008)

**기준**: 기업회계기준서 제1008호 · **상태**: Draft · **작성일**: 2026-06-22

## 1. 처리
- **회계정책 변경**: 원칙적으로 **소급 적용**(비교표시 재작성·이익잉여금 기초 조정).
- **회계추정 변경**: **전진 적용**(당기 이후).
- **오류 수정**: 중요한 전기오류는 **소급 재작성**(역분개+비교 재작성).

## 2. 등록·공시
- 변경유형(정책/추정/오류)·관련 기준서·처리방법(소급/전진)·영향액을 등록·공시한다.

## 3. 적용 한계
- 소급 재작성의 실제 전기는 일반 전표/역분개로 수행(자동 비교표시 재생성은 후속). 본 기능은 등록·공시 골격.

## 4. 변경 이력
- v0.1 (2026-06-22) 최초 제정.
