# 회계정책서 — 영업부문 (K-IFRS 1108)

**기준**: 기업회계기준서 제1108호(영업부문) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 부문 식별·공시
- 경영진이 자원배분·성과평가에 사용하는 **진료과(department)** 를 영업부문으로 본다.
- 부문별 수익·손익·자산을 공시하고, **보고부문 정량 임계**(수익·손익절대값·자산 중 하나라도 전체의 10% 이상)를
  충족하는 부문을 보고부문으로 식별한다.

## 2. 측정
- 부문 수익·손익: 진료과 손익(보험 결정수익−배부원가−삭감, costing). 부문 자산: 유형자산 장부가(부서 귀속).
- 신규 측정 없음 — 기존 진료과 손익·자산 형식화.

## 3. 적용 한계
- 부문 부채·부문 간 거래 제거는 후속. 단일 사업(의료) 가정.
