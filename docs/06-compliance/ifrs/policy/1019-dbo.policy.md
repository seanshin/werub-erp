# 회계정책서 — 퇴직급여 확정급여채무 (K-IFRS 1019)

**기준**: 기업회계기준서 제1019호(종업원급여) · **상태**: Draft · **작성일**: 2026-06-22

## 1. 인식·측정
- 확정급여제도(DB)의 확정급여채무(DBO)는 **예측단위적립방식(PUC, 간이)** 으로 측정한다.
- 정상원가(당기 근무로 증가하는 채무)는 월별 적립으로 당기손익(퇴직급여 5320)에 인식한다.
- 할인율·임금상승률 등 **보험수리적 가정 변경·경험조정(재측정요소)** 은 기타포괄손익(OCI, 보험수리적손익 3410)에
  인식하고 후속 기간 당기손익으로 재분류하지 않는다.
- 확정기여제도(DC)는 기여금을 비용·미지급(2110)으로 인식한다.

## 2. 가정
- 할인율·임금상승률·정년은 `hr.actuarial_assumptions`(시점관리). 기본 할인 4.0%·임금상승 3.0%·정년 60.

## 3. 표시
- 확정급여채무(2120) 부채, 보험수리적손익(3410)은 OCI(자본). 정상원가(5320)는 손익.

## 4. 적용 한계 / 예외
- **간이 PUC**: DBO = 명목추계 × ((1+임금상승)/(1+할인율))^잔여근속. 사망률·이직률 테이블 미반영.
- 정상원가/이자원가/재측정의 정밀 분해 대신, 월별 명목적립(P/L) + 명목 대비 보험수리 차액(OCI)로 단순화.
- 생년월일 미상 직원은 잔여근속 산정 불가 → 명목 유지(보험수리 조정 제외).
- **완전 보험수리적 평가는 보험계리사(외부) 영역** — 본 구현은 기초 추정·가정 투명화.
