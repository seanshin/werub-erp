## 시스템 특성

- **프로파일**: 트래픽 저부하(동시 ~50명) × 도메인 고복잡(심사·고시·규제·회계) — *분산이 아닌 정합성에 투자*
- **아키텍처**: Modular Monolith (FastAPI, 11 Bounded Context) + 비동기 워커 2종 — 풀 MSA 명시적 기각
- **배포**: 병원 격리망 on-prem, **HIS 구동 서버 동거**(공유 PostgreSQL·Redis를 격리 자원으로 재사용),
  외부 통신은 프록시/SSRF 화이트리스트
- **인증**: **HIS SSO**(HIS가 IdP, 공유 시크릿 JWT, JIT 프로비저닝) — ERP 자체 비밀번호 미저장
- **연동**: HIS(환자·수납)·Clinic 그룹웨어(직원·근태·**전자결재 W.Sign**)·심평원 통보서·공공 수가 API ·
  AI 색인 발신 — 전부 ACL 어댑터 + 스테이징 + 멱등 소비

## 주요 기능 흐름

- **재무 일관 원장**: 수납·청구·구매·급여·자산 → **전표** → 재무제표(시산표·손익·재무상태표) →
  고정자산(취득·감가·처분) → 채권채무·자금수지 → 경영분석 BI. 모든 단계 대차 자가검증.
- **구매 procure-to-pay**: 발주 → 승인 → 입고검수 → **미지급금 자동생성** → 지급(채권채무).
- **급여 완결**: 명세·근무표 자동편성 → 4대보험·퇴직금·연말정산 → 원천징수·공단신고.
- **보험 사전·후처리**: 청구 전 **사전심사 룰엔진**(삭감 예방, AI P0 공시 검색) + 통보서 수신·삭감·이의신청.
- **의료진 급여**: 직군·고용형태 분류 → 직종별 수당 자동명세 → 의료진 개별계약·**성과급**(실적→산정→승인→전표).

## 배포 (HIS 동거)

운영은 **HIS 구동 서버 동거** — 공유 `docker-postgres`(별도 `erp` DB)·`docker-redis`(DB 1), 포트
`8001`(core)·`3010`(web), nginx `/erp/` 3-way 분기. 자세한 절차·트러블슈팅은

```bash
# 로컬→서버 소스 반입(격리망: git clone 대신 rsync) 후
docker compose -f infra/docker-compose.coloc.yml up -d --build   # 마이그레이션 자동(alembic)
```

> ⚠️ **공유 PG 연결 슬롯 경쟁(백로그)**: 같은 PostgreSQL을 HIS·OpenPACS와 공유(`max_connections=200`).
> OpenPACS가 유휴 커넥션을 누수하면 슬롯이 고갈돼 ERP SSO/로그인이 간헐 실패할 수 있음(ERP 회귀 아님).
> ERP는 풀을 작게(10+5)·`pre_ping`·`recycle 1800s`·`timeout 10s`로 매너 유지 중. **근본 해결 = DB 서비스별

## 핵심 설계 결정 (근거: docs/02-design)

- **temporal 수가 마스터**: `valid_from~valid_to`, 과거 정산 100% 재현, EXCLUDE(GiST) 겹침 DB 차단
- **UoW 규약**: 모든 쓰기 인터페이스 `session` 첫 인자 — 트랜잭션은 유스케이스 소유(수납→전표 단일 Tx)
- **전표 멱등**: `(source_module, source_ref)` UNIQUE — 워커/연동 중복 소비 안전
- **회계 자가검증**: 재무상태표 `balanced` = 자산−부채 vs 독립 산출 누적순이익 대조(운영 정합버그 적발 실적)
- **마약류 append-only**: DB UPDATE/DELETE REVOKE + 해시 체인 + 정정 레코드
- **연동 보안**: SSRF 화이트리스트·TLS·Bearer/X-Integration-Key·콜백 HMAC·멱등 스테이징(inbox)
- **PDF 보안**: WeasyPrint 커스텀 url_fetcher — `file://`·`http(s)`·`data:` 차단(LFI/SSRF)
